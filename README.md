# TradPlus Smaato Adapter Swift Package

Swift Package Manager support for the TradPlus Smaato adapter (15.18.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-Smaato.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-Smaato.git", exact: "15.18.0")
```

Third-party dependency: Smaato SDK `23.2.3`. Minimum iOS 12.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.18.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
